Brokerage Reconciliation Guide

Read this once before starting a matching or write-off run.

← Open tool
Start here

Use the tool only after source records are ready

The tool creates a Brokerage Reconciliation audit record and starts the selected action in the background. It does not replace source-data validation.

01

Check source records

Matching reads submitted Brokerage Statements with unallocated brokerage and submitted Policy Registers with outstanding brokerage. Confirm insurer, policy number, dates, and brokerage values first.

02

Select the statement period

Choose the insurer and the statement month/year that belong to the Brokerage Statement records you want to process. The reconciliation date becomes the settlement date for generated records.

03

Choose earlier-business handling

Keep Include Earlier Business enabled to consider eligible Policy Registers from the selected month and earlier. Turn it off to consider only the selected business month.

04

Generate Matches

Use this for normal statement-to-policy matching. The background job checks eligible statements and creates system-generated Brokerage Settlement records for matching balances.

05

Generate Write-offs

Enter a positive Write-off Limit first. Only eligible policy balances that are less than or equal to that limit can be written off; a negative or zero limit cannot start this action.

06

Follow and review the run

Use the Run Status card while the job is queued or processing. After completion, open the audit record or settlements in Desk to review the generated system records.

✓

Important: Do not start a second run for the same records until the current run has completed and its audit result has been reviewed.
